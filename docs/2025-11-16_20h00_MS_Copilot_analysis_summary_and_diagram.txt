🗺️ System State Diagram (simplified)
Cardputer (Controller)
Idle / Display Sleep

→ keypress or button press → Wake / Active

Active

→ Ctrl+G → Send CMD_MORSE_GO

→ Ctrl+E → Send CMD_MORSE_END

→ Ctrl+R → Send CMD_RESET

→ Ctrl+V → Send CMD_VOLUME_CHG

→ Speed keys → Send CMD_SPEED_CHG

Feedback

Each command → LED blink (color-coded) + banner feedback

Timeout

→ no activity → Idle / Display Sleep

-----------------
Atom Echo (Responder)
Idle / Listening

→ Receive CMD_MORSE_GO → Morse Sending

→ Receive CMD_MORSE_END → Stop Morse

→ Receive CMD_RESET → Reset / Reboot

→ Receive CMD_VOLUME_CHG → Adjust Volume

→ Receive CMD_SPEED_CHG → Adjust Morse Speed

Morse Sending

→ Buffer processed → back to Idle / Listening

→ CMD_MORSE_END → back to Idle / Listening

Reset / Reboot

→ Restart sequence → back to Idle / Listening

🔄 Flow Example

Cardputer sleeps → user presses Ctrl+G → wakes, sends CMD_MORSE_GO.

Echo receives → enters Morse Sending, outputs “paris ” at 1200 Hz.

User presses Ctrl+E → Cardputer sends CMD_MORSE_END.

Echo stops Morse → returns to Idle / Listening.

User presses Ctrl+R → Cardputer sends CMD_RESET.

Echo reboots → re-enters Idle / Listening.

Cardputer display sleeps again after inactivity.
